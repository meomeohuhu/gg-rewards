Kết nối trình duyệt

Chạy runner trên máy có giao diện Edge để thực hiện nhiệm vụ.

01 · Chuẩn bị tiện ích

npm ci
npm run prepare:extension

02 · Mở runner trong terminal thứ hai

npm run runner

Runner và web cần dùng cùng máy / thư mục dữ liệu. Runner dùng tiện ích Search Auto từ vanhobmt99/reward ở commit cố định; xem README để biết cách hoạt động.

03 · Đăng nhập và chạy

Thêm email → chọn tài khoản → “Mở đăng nhập”. Đăng nhập Microsoft trong cửa sổ Edge, sau đó đóng cửa sổ khi hoàn tất. Tiếp theo chọn “Chạy đã chọn”. Mỗi hồ sơ chỉ dùng một tài khoản; hãy kiểm tra email đăng nhập trước khi chạy.

Web không lưu mật khẩu, không tự vượt CAPTCHA hay xác thực hai bước. Điểm chưa được đồng bộ sẽ hiển thị “—”.
